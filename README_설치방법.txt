나의 물건 관리 PWA 패키지

구성
- index.html: 기존 4차 앱에 PWA 연결 기능을 추가한 파일
- manifest.webmanifest: 앱 이름, 아이콘, 실행 화면 설정
- sw.js: 앱 화면과 기본 파일을 캐시하는 서비스 워커
- icons/: 홈 화면 아이콘

설치 방법 (Android / Chrome)
1. 이 폴더 안의 파일을 모두 유지한 채 HTTPS를 지원하는 정적 웹호스팅에 업로드합니다.
   index.html, manifest.webmanifest, sw.js, icons 폴더가 같은 경로 구조여야 합니다.
2. 업로드된 HTTPS 주소를 스마트폰 Chrome으로 엽니다.
3. 한 번 온라인 상태에서 페이지를 완전히 불러옵니다.
4. Chrome 메뉴(⋮)에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
5. 홈 화면의 '물건 관리' 아이콘으로 실행합니다.

데이터 주의
- 기존 앱과 동일한 localStorage 키(mythings-v3)를 사용합니다.
- 다만 file://로 직접 연 HTML과 새 HTTPS 웹사이트는 브라우저 저장 공간이 다를 수 있습니다.
- 기존 파일에서 JSON 백업을 먼저 만들고, 새 PWA를 연 뒤 '백업 복원'으로 가져오세요.
- PWA에서 입력한 데이터는 해당 HTTPS 사이트의 브라우저 저장 공간에 보관됩니다. 브라우저 사이트 데이터 삭제 시 지워질 수 있으므로 JSON 백업을 권장합니다.

오프라인
- 처음 온라인으로 앱을 연 뒤 기본 화면과 앱 파일을 캐시합니다.
- 엑셀 내보내기는 SheetJS 라이브러리를 처음 내려받아 캐시한 뒤에는 오프라인에서도 동작할 수 있습니다.
- 최초 접속 및 설치에는 인터넷 연결과 HTTPS가 필요합니다.

참고
- 이 패키지는 PWA로 배포할 준비가 된 정적 웹앱입니다. ZIP 파일 자체를 눌러 설치하는 것은 아니며, HTTPS 호스팅이 필요합니다.
